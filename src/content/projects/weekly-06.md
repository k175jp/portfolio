# Overview

A simple real-time chat application using Go and WebSockets.

The project demonstrates how to establish and manage stateful, bidirectional WebSocket connections to enable real-time message broadcasting between clients.

---

# Tech Stack

- Go
- WebSockets

---

# Features

- Real-time bidirectional chat
- WebSocket communication
- Simple broadcast mechanism

---

# Notes

Focused on understanding the mechanics of WebSocket handshakes, stateful connection management in Go, and implementing a basic message broadcast system.
