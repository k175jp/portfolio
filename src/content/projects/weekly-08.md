# Overview

A minimalist task management dashboard built with Go and HTMX, focusing on server-side rendering and lightweight dynamic updates.

The project demonstrates how to create a dynamic CRUD application (Create, Read, Update, Delete) using HTMX, reducing the need for heavy client-side JavaScript frameworks.

---

# Tech Stack

- Go (net/http, html/template)
- HTMX
- Docker / Docker Compose

---

# Features

- Task creation (POST)
- Task deletion (DELETE)
- Task status toggling (PUT)
- Partial UI updates via HTMX (no full page reloads)
- In-memory task persistence

---

# Notes

Focused on exploring HTMX-driven development, server-side template partials, and implementing RESTful interaction patterns in a containerized Go environment.
