# Overview

A lightweight, blazing-fast API Mock Server CLI built with Rust.

It allows frontend developers to instantly spin up a mock HTTP server from a single JSON configuration file, streamlining local prototyping and integration testing.

---

# Tech Stack

- Rust
- axum / tokio
- serde
- clap

---

# Features

- Dynamic Query Routing
- Request Body Echoing
- Asynchronous Latency Simulation
- Dynamic Template Replacement
- Built-in CORS Handling
- Zero-Dependency Runtime

---

# Notes

Focused on practicing Rust's ownership model, trait safety, and high-performance asynchronous request handling.
