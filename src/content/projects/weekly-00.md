# Overview

A personal portfolio website built with Astro.

This project serves as the foundational hub for my weekly development series, showcasing various projects implemented over time.

---

# Tech Stack

- Astro
- TypeScript
- Tailwind CSS
- GitHub Actions

---

# Features

- Personal introduction and overview
- Showcase of projects (rendered from Markdown in `src/content/projects`)
- Responsive and modern UI
- High performance using Astro's static site generation
- Automated deployment with GitHub Actions

---

# Notes

Focused on building a high-performance static site and establishing a centralized platform for documenting and presenting technical projects.
